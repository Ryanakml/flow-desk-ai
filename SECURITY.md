# Security policy

Do not report vulnerabilities in public issues. Use GitHub private vulnerability reporting at `Ryanakml/FlowDesk`, including affected revision, sanitized reproduction, impact, and suggested mitigation. Never attach customer data, credentials, access tokens, message bodies, or raw provider payloads.

The maintainers will acknowledge a report within two business days, assign severity and an owner, and provide a remediation status within five business days. Disclosure timing is coordinated with the reporter after a supported release is available. Only the latest release line receives security fixes before general availability.

Repository rules prohibit committed secrets. Rotate any exposed credential immediately; removing it from Git history is not sufficient.
